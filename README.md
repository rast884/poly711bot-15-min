# PolyBot — BTC 15M Торговый бот

Виртуальный счёт $100 · Ставки $5 · 09:00–23:00 МСК · Telegram уведомления

---

## 🚀 Деплой за 5 минут

### Шаг 1 — Создать Telegram бота

1. Открыть [@BotFather](https://t.me/BotFather) в Telegram
2. Написать `/newbot`
3. Придумать имя и username (например `MyPolyBot`)
4. Скопировать **токен** — выглядит так: `7123456789:AAHxxx...`

### Шаг 2 — Получить Chat ID

1. Открыть [@userinfobot](https://t.me/userinfobot)
2. Написать `/start`
3. Скопировать **Id** — это ваш Chat ID (например `123456789`)

### Шаг 3 — Задеплоить на Railway

1. Зайти на [railway.app](https://railway.app) → **New Project**
2. Выбрать **Deploy from GitHub repo**
3. Загрузить эти файлы в GitHub репозиторий (или использовать Railway CLI)
4. В Railway открыть **Variables** и добавить:

```
TG_TOKEN  = 7123456789:AAHxxx...ваш_токен...
TG_CHAT_ID = 123456789
```

5. Railway автоматически запустит бота

### Альтернатива — Railway CLI (быстрее)

```bash
# Установить CLI
npm install -g @railway/cli

# Войти
railway login

# Создать проект и задеплоить
railway init
railway up

# Добавить переменные
railway variables set TG_TOKEN=ваш_токен
railway variables set TG_CHAT_ID=ваш_chat_id
```

## 📱 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск и приветствие |
| `/status` | Баланс, P&L, текущая ставка |
| `/bet` | Поставить прямо сейчас |
| `/pause` | Пауза / возобновление |
| `/reset` | Сброс (баланс → $100) |
| `/analysis` | Анализ рынка (RSI, MACD, тренд) |

## 📊 Уведомления

Бот присылает уведомление при каждом событии:

- ✅ **Ставка размещена** — направление, цена входа, RSI, уверенность
- ✅/❌ **Результат** — выигрыш/проигрыш, P&L, win rate
- 🌙 **Итог дня** — ежедневный отчёт в 23:00 МСК

## ⚙️ Настройки (в bot.py)

```python
BET_AMOUNT = 5.0      # размер ставки в $
INTERVAL   = 15 * 60  # интервал в секундах (15 мин)
START_HOUR = 9        # начало торгов МСК
END_HOUR   = 23       # конец торгов МСК
```

---

## 🔧 Алгоритм ставок

1. Получает свечи BTC/USD по WebSocket с Binance (реальные данные)
2. Считает RSI(14), MACD(12/26), тренд (5 свечей)
3. Голосование сигналов → UP или DOWN
4. Ставит $5, через 15 мин смотрит результат
5. Выигрыш = +$4.40 (88%), проигрыш = -$5.00
